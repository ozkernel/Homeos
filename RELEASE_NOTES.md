# HomeOS v2.0.0

HomeOS brings your home-lab servers, network and media services into one self-hosted dashboard, with a personal workspace for everyday tasks.

## Included in this release

- Unraid and Proxmox VE monitoring for hosts, storage, containers and virtual machines, with history and alerts.
- UniFi network and WAN activity, plus AdGuard Home DNS statistics.
- Plex, Jellyfin and Seerr views, together with Sonarr, Radarr, Prowlarr and qBittorrent activity.
- FFmpeg-backed media and audio features.
- Shortcuts, notes, files, music, wiki pages, tasks, calendar events and device records.
- Themes, icons, widgets, notifications, administrator and viewer accounts, active sessions and Demo Mode.

## Installation

The official image reference is `ghcr.io/ozkernel/homeos:2.0.0` for **Linux amd64**. It can be pulled **after publication**. Users can install it using the public Docker Compose files or the Unraid template; the private source code is not required.
